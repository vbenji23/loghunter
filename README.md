# 🛡️ LogHunter

Détecteur d'attaques dans les fichiers de logs, écrit en Python.

> 🚧 Projet en cours de développement

## 🎯 Objectif

LogHunter analyse des fichiers de logs (SSH, serveurs web) pour repérer
automatiquement des comportements suspects, comme le ferait un analyste SOC.

## ✨ Fonctionnalités prévues

- [ ] Lecture de fichiers de logs
- [ ] Extraction des informations (IP, utilisateur, date) avec des regex
- [ ] Détection de brute force SSH
- [ ] Détection de scans web (nombreuses erreurs 404)
- [ ] Détection de tentatives d'injection (SQLi, XSS, path traversal)
- [ ] Rapport coloré dans le terminal
- [ ] Export des résultats en JSON

## 🛠️ Technologies

- Python 3
- Bibliothèque standard uniquement (re, argparse, json)
